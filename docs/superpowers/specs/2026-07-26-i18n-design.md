# ClipVault i18n 国际化支持

## Summary

引入 `vue-i18n` 库，将所有硬编码中文 UI 文本抽取为 locale 消息文件（zh-CN / en-US），语言偏好存储在 Rust Settings 中（与现有设置一致），主窗口和托盘菜单窗口共享同一语言配置。

---

## 1. 依赖安装

```bash
npm install vue-i18n@^10
```

## 3. i18n 实例创建

`src/locales/index.ts`:

```ts
import { createI18n } from 'vue-i18n'
import zhCN from './zh-CN'
import enUS from './en-US'

export const i18n = createI18n({
  legacy: false,           // Composition API 模式
  locale: 'zh-CN',         // 默认，启动后从 settings 覆盖
  fallbackLocale: 'en-US',
  messages: { 'zh-CN': zhCN, 'en-US': enUS },
})

export function setLocale(locale: string) {
  ;(i18n.global.locale as unknown as { value: string }).value = locale
  document.documentElement.lang = locale
}
```

## 5. Settings 扩展（Rust + TS）

### `src/types.ts` — Settings 接口新增字段

```ts
language: 'zh-CN' | 'en-US' | 'system';
```

### `src/stores/settings.ts` — DEFAULT_SETTINGS 新增

```ts
language: 'system',  // 默认跟随系统
```

### `src-tauri/src/lib.rs` — Rust Settings 结构体新增

```rust
pub language: String,  // "zh-CN" | "en-US" | "system"
```

并在 `Default` impl 中设为 `"system"`。

### 语言解析逻辑

在 `src/locales/index.ts` 或 `App.vue` onMounted 中：

```ts
function resolveLocale(lang: string): string {
  if (lang === 'system') {
    return navigator.language.startsWith('zh') ? 'zh-CN' : 'en-US'
  }
  return lang
}
```

在 `App.vue` 的 `settingsStore.loadSettings()` 之后调用 `setLocale(resolveLocale(settings.language))`，并 watch `settings.language` 变化实时更新。

## 6. 组件文本替换（核心工作量）

逐组件将硬编码字符串替换为 `$t('key')` 或 `t('key')`（script setup 中用 `useI18n()`）。

涉及文件清单：

| 文件 | 主要文本 |
|------|----------|
| `src/components/SettingsWindow.vue` | 导航标签、所有设置项 label/desc、帮助指南、关于 |
| `src/components/FloatingPanel.vue` | 筛选 tabs、回收站横幅、按钮 title |
| `src/components/SearchBar.vue` | placeholder、aria-label |
| `src/components/RecordList.vue` | 右键菜单、空状态、排序选项、分类标题、加载文本 |
| `src/components/SideBar.vue` | 分类导航、标签管理、快捷菜单 |
| `src/components/BatchBar.vue` | 已选 N 项、复制/收藏/删除 |
| `src/components/CaptureStatus.vue` | 捕获状态文本 |
| `src/components/WelcomeDialog.vue` | 欢迎步骤 |
| `src/components/PreviewPane.vue` | 操作按钮、类型标签、元信息 |
| `src/components/AliasDialog.vue` | 对话框标题/按钮 |
| `src/components/TagDialog.vue` | 标签对话框 |
| `src/utils/trayMenuItems.ts` | 托盘菜单项 label |
| `src/stores/clipboard.ts` | LIST_SORT_OPTIONS labels |

对于 `trayMenuItems.ts` 和 `clipboard.ts` 中的静态数组，改为函数形式接收 `t` 参数，或改为 computed 从 i18n 实例取值。

## 7. 设置界面增加语言切换

在 `SettingsWindow.vue` 的「系统」section 中新增一行：

```
语言 / Language
[中文] [English] [跟随系统]   ← segmented 三段按钮
```

绑定 `settings.language`，更新后调用 `setLocale(resolveLocale(value))`。
